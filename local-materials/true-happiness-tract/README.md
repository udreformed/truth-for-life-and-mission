# 참된 행복 전도책자 정리

이 폴더는 사이트의 `PDF 자료`에 올린 전도책자 자료를 구분하기 위한 메모입니다.

## 사이트 표시 제목

- 태국어: `ความสุขที่แท้จริง — ทำไมมนุษย์จึงยังว่างเปล่า แม้มีทุกสิ่ง? (หนังสือแจกจ่าย)`
- 한국어: `참된 행복 — 왜 인간은 모든 것을 가져도 여전히 공허한가? (전도책자)`
- 영어: `True Happiness — Why Are We Still Empty Even When We Have Everything? (Gospel Tract)`

## 성격

- J. C. Ryle의 글을 바탕으로 만든 전도책자입니다.
- 태국어 원본이 기준입니다.
- 한국어와 영어 파일은 태국어 원본에 대한 직역본입니다.
- 무료도서의 J. C. Ryle 책 `Happiness / 참된 행복`과는 별도 자료입니다.
