# 관리자 시작 안내

## 지금 이 컴퓨터에서 시험하기

- 관리자 화면: `http://127.0.0.1:4323/admin/`
- 유용한 사이트 페이지: `http://127.0.0.1:4323/th/useful-sites/`
- 로컬 시험 이메일: `admin1@example.com`, `admin2@example.com`, `admin3@example.com`

로컬 주소는 현재 이 컴퓨터에서만 열립니다. 관리자 화면에서 시험 이메일을 입력하고 `Connect`를 누르면 자료 작성 화면이 나타납니다.

## 정식 운영 주소를 만들기 위해 필요한 것

1. Cloudflare 계정 소유자 1명
2. Cloudflare에 연결할 실제 도메인
3. 관리자 3명의 실제 이메일 주소

이 세 가지가 정해지면 D1, R2, Worker, Access를 연결하고 정식 주소를 배포할 수 있습니다. 정식 관리자 주소는 `https://도메인/admin/` 형태가 됩니다.

## 관리자 3명 가입

1. 대표 관리자가 Cloudflare 계정을 만듭니다.
2. 다른 두 명을 Cloudflare 계정 멤버로 이메일 초대합니다.
3. 초대받은 두 명은 각자 자신의 Cloudflare 계정을 만들거나 기존 계정으로 초대를 수락합니다.
4. 세 명 모두 MFA를 켭니다.
5. 세 이메일을 Cloudflare Access 허용 정책과 D1 `users` 표에 동일하게 등록합니다.

## 매일 로그인하고 게시하는 방법

1. `https://도메인/admin/`에 접속합니다.
2. 자신의 Cloudflare 계정으로 로그인합니다.
3. 자료 유형과 언어를 선택하고 제목, 주소용 영문 이름(slug), 요약, 본문을 작성합니다.
4. 동영상은 YouTube 주소를 붙여 넣습니다.
5. 먼저 초안으로 저장하거나 `Publish immediately`를 선택해 바로 게시합니다.
6. 이미지나 PDF는 자료를 한 번 저장한 뒤 업로드합니다.

세 명은 서로 다른 계정으로 접속하지만 모두 직접 게시할 수 있습니다. 앱이 별도 비밀번호를 저장하지 않으므로 비밀번호 재설정이나 계정 DB 관리 부담이 없습니다.

## 더 간단한 대안

Cloudflare 계정 가입 대신 이메일 One-time PIN을 쓸 수도 있습니다. 이 경우 허용된 이메일 주소를 입력하고 받은 1회용 코드를 넣으면 됩니다. 다만 장기 운영에는 각자 Cloudflare 계정과 MFA를 사용하는 방식을 권장합니다.
